# Проверка перед передачей коллегам

## Windows-сборка

- Запустить `build_exe.bat` на Windows 10/11 x64 с Python 3.12 x64; сохранить журнал.
- Убедиться, что pytest прошёл, PyInstaller завершился, self-test exe имеет код 0, создан ZIP.
- На другом Windows-ПК без Python распаковать ZIP; запустить exe обычным пользователем. Проверить notices/licenses, не удалять их из поставки.
- Путь к приложению и фотографиям: кириллица и пробелы. Проверить масштаб экрана 100%, 150%, 200% и экран 1366×768.
- Двойной щелчок exe открывает интерфейс без консоли. Выбор/перетаскивание папки, подпапки, ручная рамка, сохранение/загрузка рецепта работают.
- Экспорт JPEG и TIFF в новую подпапку. Проверить ICC, размер, PPI в независимом редакторе. Оригиналы совпадают по хешам.
- Отмена партии, повреждённый снимок, защищённая от записи папка, мало места на диске: понятная ошибка, оригиналы целы.
- Повторный запуск не перезаписывает прошлые результаты и не подхватывает PrintPrep_*.

## Реальная печать

У оператора получить требования: точный размер бумаги, PPI, RGB/CMYK, профиль и его назначение (proof или conversion), формат, вылет/безопасная зона, автокоррекция, настройка borderless.

Сделать пробную партию из 8–12 снимков: светлая и тёмная кожа, насыщенный красный/синий, нейтральный серый, мягкий градиент, текстура, важные объекты у краёв, маленький исходник, квадрат, портрет, пейзаж. Для каждого сравнить оригинал / без улучшений / мягкие улучшения.

Проверить линейкой физический размер и поля. Сравнить оттенки при нейтральном освещении. Исключить двойное управление цветом. Отдельно проверить ICC-пробу и ожидания оператора. При необходимости сохранить согласованный рецепт для конкретной машины/бумаги.

Эти проверки требуют Windows и физического оборудования. Они не выполнены облачными тестами и не могут считаться пройденными заранее.

## Пресеты, дополнительные панели и нейро ×2

- Проверить последовательность папка → карточка пресета → прямая обработка всей партии. Просмотр должен открываться отдельной кнопкой; до него декодирование больших предпросмотров не запускается.
- Проверить отдельное окно настроек: отмена возвращает предыдущие параметры. На экране 1080×760 карточки не перекрываются, а основная кнопка доступна без прокрутки.
- Сохранить свой именованный пресет, перезапустить приложение, загрузить; значения совпадают. Перенести JSON-рецепт на другой ПК с разрешённым ICC отдельно.
- Проверить пресеты на коже, тёплом свете, снегу/белом фоне и ночной сцене. Авто-ББ не должен включаться без действия пользователя.
- Для небольшого исходника сравнить Lanczos / FSRCNN 0% / 60% / 100% при масштабе 100% и на отпечатке. Не утверждать восстановление реальных надписей/волос по дорисованному результату.
- Нейроувеличение не запускается при уменьшении, ограничено 8-Мп входным кадром. Отчёт показывает применение/пропуск. Предпросмотр нейро не рассчитывает; проверять экспорт.
- На слабом CPU измерить время реальной партии, следить за памятью и отменой. Модель не скачивается из интернета и не требует GPU.
