## Ограничения проверки

Windows exe не собран и не запущен в этой Linux-среде. Подготовлены Windows build script и workflow; перед передачей коллегам нужен запуск новой сборки на Windows, включая чистый ПК без Python и масштабирование экрана 100/125/150%.

Не было физического принтера, бумаги и калиброванного монитора. Цвет конкретного отпечатка и работа драйвера не подтверждены. ICC-проба на экране приближённая; редактор явно показывает рабочий sRGB.

Нет доказательств универсального превосходства над Photoshop. FSRCNN — компактная модель увеличения ×2, не реставратор любых фотографий; она применяется только при увеличении, возможны артефакты. Предпросмотр теперь использует её фактический результат. Выход 8-битный, рабочий охват sRGB. Режим без уменьшения предотвращает прежнюю неявную потерю разрешения до размера 10×15; уже сохранённый пользователем размер восстанавливается как раньше.

Исследованные источники и ограничения доступа перечислены в [RESEARCH.md](RESEARCH.md). Сравнения скорости и эстетического качества с коммерческими редакторами не проводились.
