16 октября 2026. Linux x86_64, Python 3.12.14.

- `python print_prep.py --self-test`: PASS. Проверяет обычный экспорт/ICC/геометрию, запуск UI и inference встроенной FSRCNN.
- PyInstaller собрал Linux onefile; `dist/PrintPrep-linux --self-test`: PASS. Проверены ресурсы и inference внутри упакованного приложения. Размер этой Linux-сборки около 145 МБ; маленькая модель не делает весь Qt/OpenCV-дистрибутив размером 39 КБ. Размер Windows exe пока неизвестен.

- Снимок работающего интерфейса: [interface.png](interface.png); использован синтетический демонстрационный пейзаж. Реальная фотография пользователя в проект не добавлялась.

## Что не проверено

- Windows exe не собран и не запускался: среда Linux. Подготовлены `build_exe.bat` и `.github/workflows/windows.yml`; их Windows-результат не утверждается. Self-test и тесты должны пройти на Windows, затем нужен запуск на чистом ПК без Python.
- Не было физического принтера, бумаги, калиброванного монитора и пробных отпечатков. Совпадение цвета и работа конкретного драйвера не подтверждены.
- Прямой доступ к сайтам лабораторий/студий, Pixls.us и части профессиональных справочников заблокирован прокси 403. Прочитанные GitHub-обсуждения и технические источники перечислены в RESEARCH.md; остальные страницы не выдаются за просмотренные. Сетевые дополнения сохранены в черновик, в текущей политике они ещё не применены.
- Нет доказательств универсального превосходства над Photoshop. FSRCNN не state-of-the-art реставратор; возможны артефакты. Выход 8-битный, рабочий охват sRGB.
- Код подготовлен в рабочем каталоге. Коммиты, push, удалённый CI и публикация среды не выполнялись.
