# Print Prep 2.0 — план переработки

> Исторический документ: внутренний план версии 2.0, составленный до её реализации. Актуальное описание — в [README](../README.md) и [RESEARCH.md](RESEARCH.md).

Дата: 16 октября 2026. Основа — версия 1.1 (коммит `bee4ec3`), отзыв пользователя после первого показа и ресёрч практик печати и интерфейсов фоторедакторов.

## Цель продукта

Открыл папку → выбрал пресет → «Подготовить». Оригиналы не меняются, результат пишется в подпапку. Тот, кому нужно больше, может посмотреть любой снимок, поправить кадр и цвет, сохранить свой пресет и передать его другим людям. Обработка локальная, без облака.

## Что говорят источники

- **Цвет:** лаборатории и минилабы (Frontier, Noritsu) ждут sRGB. ICC/CMYK — только по требованию типографии.
- **Разрешение:** 300 PPI на печатном размере, 240 — хорошо, ниже 150 — заметно хуже. 10×15 — это 4×6″ (102×152 мм, 1800×1200 px).
- **Выходная резкость** — после ресайза, под бумагу и PPI. Матовой бумаге нужно больше, чем глянцевой. По Фрейзеру глаз различает ~1/100 дюйма, поэтому радиус масштабируется с PPI. Так работает Lightroom: «Резкость для: глянцевая/матовая, Слабая/Стандарт/Сильная».
- **Отпечаток темнее экрана** — частая жалоба. У Lightroom для этого есть «Print Adjustment: яркость/контраст». Это грубая эмпирическая поправка, поэтому её надо делать отключаемой и сохранять в пресете под конкретную бумагу.
- **Обрезка при печати без полей:** важное держать в нескольких мм от края. Показываем безопасную зону.
- **Автокоррекция лабораторного уровня:** у Perfectly Clear есть каналы-пресеты, полностью автоматический пакет и выравнивание лиц и кожи. Аналог у нас — умный авто-движок с анализом каждого снимка, силой и ручными поправками.
- **Интерфейс:** профессиональные редакторы (Lightroom, Capture One, darktable) используют одно рабочее окно: слева библиотека и пресеты, в центре просмотр, снизу лента кадров, справа инспектор со сворачиваемыми секциями. Фон вокруг фото — нейтральный серый.

## Новый интерфейс: одно рабочее окно

```
┌ Print Prep ─ [Папка ▾] Съёмка/Горы · 48 фото ──────────── [Подготовить 48 фото →] ┐
│ ПРЕСЕТЫ        │                                          │ [ Все фото | Этот снимок ] │
│ ● Без уменьш.  │                                          │ ▾ Размер и кадр            │
│   10×15 лаб.   │          ПРОСМОТР (живой)                │ ▾ Свет и цвет   [Авто ●]   │
│   4K           │     до | после · вписать / 100%          │   Экспозиция  ──●──  +0.3  │
│   …            │     [⏳ Нейросеть ×4 · 37%]              │   …                        │
│ МОИ            │                                          │ ▸ Детали и резкость        │
│   Саша · глянец│                                          │ ▸ Стиль                    │
│ [+ Новый]      │                                          │ ▸ Нейросеть                │
│                ├──────────────────────────────────────────┤ ▸ Файл и цвет              │
│                │ [▢][▢][▢][▢] лента кадров  ✎ ⚠          │                            │
└────────────────┴──────────────────────────────────────────┴────────────────────────────┘
```

- **Пустое состояние:** зона перетаскивания папки, недавние папки, подсказки. Заглушки-скелеты у миниатюр, пока они грузятся.
- **Пресеты слева:** клик сразу применяет пресет ко всем фото. Изменённый пресет помечен точкой, рядом «Сохранить» и «Сбросить». В контекстном меню: дублировать, переименовать, удалить, экспорт и импорт.
- **Просмотр:** до/после со шторкой, «вписать», 100% и 200% с панорамированием, режим кадрирования (перетаскивание, колесо, поворот), безопасная зона. Внизу чипы: размер, PPI, обрезка, предупреждения.
- **Статусы поверх просмотра:** «Анализ снимка…», «Обновляем…», «Нейросеть Real-ESRGAN ×4 · 37%» с прогрессом.
- **Инспектор справа:** переключатель «Все фото / Этот снимок». Правки снимка добавляются к пресету и отмечаются значком в ленте. Ползунки в стиле Lightroom: двойной щелчок сбрасывает, значение видно, колесо не меняет значение случайно.
- **Живое применение:** любое изменение пересчитывает просмотр сразу. Отдельной кнопки «Применить» нет. Ctrl+Z — отмена.
- **Экспорт:** кнопка вверху превращается в прогресс с отменой. Закончили — баннер «Готово · Открыть папку».
- **Тема:** нейтральная тёмно-серая, один акцентный цвет. Фон просмотра можно выбрать: тёмный, средне-серый по ISO 12646 или светлый.

## Новый движок

1. **Float32 от начала до конца:** 8- и 16-битные исходники (TIFF/PNG через OpenCV), входной ICC → линейный RGB. Выход — JPEG, TIFF 8/16 бит или PNG.
2. **Быстрый предпросмотр через прокси:** просмотр считается на изображении размером с экран. Тоновые карты общие для прокси и экспорта, поэтому картинки совпадают. 100% считается по видимой области в полном разрешении, так видна настоящая резкость и нейросеть.
3. **Умный авто-движок для каждого снимка:**
   - баланс белого: обученный `LearningBasedWB` из OpenCV плюс оценка по нейтральным участкам, с ограничением;
   - экспозиция: по средней логарифмической яркости, с весом лиц;
   - чёрная и белая точки: по перцентилям;
   - контраст: по разбросу яркости;
   - тени и света: по доле провалов и пересветов;
   - сочность: по средней насыщенности;
   - шумоподавление: по оценке шума методом Иммеркера.
   Одна «сила авто» масштабирует всё. В чипах видно, что именно сделано.
4. **Ручные поправки как в Lightroom:** экспозиция, контраст, света, тени, белые, чёрные, температура, оттенок, сочность, насыщенность, чёткость, дымка, шумоподавление.
5. **Стили:** нейтральный, яркий, тёплый, мягкий портрет, кино, матовый, Ч/Б и контрастный Ч/Б, с регулируемой силой.
6. **Печать:** выходная резкость по бумаге и PPI, компенсация яркости отпечатка, безопасная зона, ICC-проба с подсветкой цветов вне охвата.
7. **Нейросети:** FSRCNN ×2 (быстро) и Real-ESRGAN general ×4 (качество, ~5 МБ, CPU), с прогрессом и отменой. Детектор лиц YuNet (~0,2 МБ) нужен для умного кадра и защиты кожи; без модели работает Haar из OpenCV.
8. **Параллельный экспорт** на нескольких ядрах, ошибка в одном файле не останавливает остальные. EXIF сохраняется без GPS, ориентация сбрасывается.
9. **Пресеты v2** с миграцией старых пресетов и рецептов 1.x.

## Порядок работ

1. Движок: конвейер, авто-анализ, стили, резкость, нейросети с прогрессом, экспорт.
2. Виджеты: ползунок, секция, переключатели, лента, просмотрщик, список пресетов.
3. Главное окно и связка с движком: живой просмотр, правки снимка, экспорт.
4. Тесты движка и интерфейса, скриншоты, сборка Windows `.exe` и self-test.
5. README и документация.

## Что сознательно не делаем сейчас

RAW и HEIC (нужны тяжёлые зависимости), прямую печать на принтер (двойное управление цветом), ретушь кожи и лиц, облако.
