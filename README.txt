PRINT PREP 2.2 — подготовка фотографий к печати
===============================================

Установка
---------
Запустите PrintPrep-Setup.exe и нажмите «Установить». Права администратора не нужны: программа
ставится в вашу папку пользователя, появляется ярлык на рабочем столе и в меню «Пуск», и Print Prep
сразу запускается. Обновление — так же: новый PrintPrep-Setup.exe → «Обновить», пресеты сохраняются.
Удаление — «Параметры» → «Приложения» → Print Prep → «Удалить».
Установщик не подписан сертификатом, поэтому Windows может показать «Система Windows защитила
ваш компьютер»: нажмите «Подробнее» → «Выполнить в любом случае».


Коротко
-------
1. Откройте папку со снимками (кнопка «Открыть папку» или перетащите папку в окно).
2. Выберите пресет слева, например «Фотолаборатория 10×15». Он сразу применяется ко всем фото.
3. Нажмите «Подготовить N фото» справа вверху.

Готовые файлы появятся в новой подпапке PrintPrep_<пресет>_<дата> рядом с оригиналами.
Оригиналы никогда не перезаписываются. Обработка полностью локальная, без интернета.

При первом запуске программа покажет короткий тур по окну (его можно пропустить клавишей Esc
и повторить в настройках приложения).


Тема, язык и настройки приложения
---------------------------------
Кнопка с ползунками справа вверху — «Настройки приложения»:
  Тема       — «Как в Windows», светлая или тёмная. Переключается сразу, папка и снимок остаются.
               Фон вокруг снимка в любой теме нейтрально-серый: так цвет оценивается честно.
  Язык       — русский или English. Приложение быстро перезапустится и откроет ту же папку.
  Анимации   — заставка и анимации загрузки; выключите на очень слабом компьютере.
  «Показать обучение ещё раз» — повторить тур.


Окно программы
--------------
Слева      — список пресетов: «Основные», «Печать», «Экран и веб», «Нейросеть» и ваши «Мои».
В центре   — живой просмотр выбранного снимка, под ним лента всех снимков папки.
Справа     — карточка пресета, гистограмма и настройки. Переключатель:
             «Все фото»    — настройки пресета для всей папки;
             «Этот снимок» — правки только выбранного фото поверх пресета.
Внизу      — строка состояния: файл, время расчёта просмотра, работа нейросети.

Любое изменение сразу видно в просмотре. Кнопки «Применить» нет.
Ctrl+Z отменяет, Ctrl+Y повторяет.

Над просмотром:
  Результат / До / после / Исходник
                          — режим просмотра. «До / после» включён по умолчанию: слева исходник,
                            справа результат, шторку можно тянуть мышью. Клавиша \ — переключить.
  По окну / 1:1 / 2:1     — масштаб. «По окну» показывает весь кадр. «1:1» — один пиксель файла
                            на один пиксель экрана: так видны настоящая резкость, шум и работа
                            нейросети. «2:1» — увеличение вдвое для проверки мелочей.
                            Двойной щелчок по снимку — 1:1 в этой точке, Ctrl+колесо — масштаб.
  Кадр (C)                — рамка кадрирования: тяните рамку, колесо — масштаб, уголки — размер.
  Поворот (Ctrl+[ / ])    — на 90° для этого снимка.
  Безопасная зона         — пунктир в 3 мм от края: при печати без полей края могут срезаться.
  Проба ICC / вне охвата  — появляются, если выбран ICC-профиль принтера.
  Фон просмотра           — тёмный, средне-серый (по ISO 12646 для оценки цвета) или светлый.

Под просмотром — чипы: итоговый размер, детализация в PPI, увеличение или уменьшение,
предупреждения, «Нейросеть ✓» или подсказка «Мало разрешения — поможет нейросеть».
Жёлтый чип вверху показывает проблемные снимки партии. По клику — список и переход к снимку.
Значки в ленте: карандаш — у снимка есть свои правки; треугольник — предупреждение.


Пресеты
-------
Клик по пресету в списке — применить ко всей папке. Выбранный пресет обведён рамкой.
Справа над настройками всегда написано, какой пресет вы настраиваете: изменения во вкладке
«Все фото» — это изменения пресета, и они сразу применяются ко всем фото папки.
Группы встроенных пресетов сворачиваются щелчком по заголовку (выбранный пресет остаётся виден).
Карточка пресета справа вверху показывает его название и параметры. Изменили настройки —
у названия появляется точка и кнопки «Сбросить» и «Сохранить» (для встроенного пресета —
«Сохранить как…»: встроенные не меняются, сохраняется ваша копия в «Мои»).
Кнопка «Пресет» в карточке — все действия: сохранить изменения, сохранить как новый,
переименовать, дублировать, сбросить, экспорт и импорт файла, удалить, управление пресетами.
«Новый» над списком сохраняет текущие настройки как новый пресет.
«…» у пресета (появляется при наведении) и правый щелчок — меню этого пресета.
«Управление пресетами» внизу списка — отдельное окно со всеми пресетами.
Файл пресета можно отправить коллегам — они импортируют его. Подходят и рецепты версии 1.x.
Меню папки → «Экспортировать рецепт» сохраняет пресет вместе с правками снимков.

Правки снимков каждой папки сохраняются автоматически и восстанавливаются при следующем открытии.


Настройки «Все фото»
--------------------
Размер и кадр
  Оригинал  — пиксели не меняются.
  Печать    — формат бумаги (10×15 = 102×152 мм и др.), свои мм, PPI (для фотопечати 300).
  Пиксели   — точный размер, есть шаблоны 4K, Full HD, Instagram.
  Сторона   — длинная сторона в пикселях, пропорции сохраняются.
  Заполнить — формат заполняется целиком, лишнее обрезается.
              Умный кадр сдвигает рамку к лицам и главному в кадре.
  Вписать   — весь кадр с полями. Цвет полей можно выбрать.

Свет и цвет
  Умная авто-коррекция анализирует каждый снимок отдельно и правит только реальные дефекты:
    • баланс белого: нейтральные поверхности снимка «голосуют» за цвет освещения, фактурные
      поверхности весят больше гладкого неба и фона. Настоящий оттенок (неверный ББ камеры)
      сдвигает и тени, и света — он исправляется почти полностью. Тёплый свет заката или ламп
      оставляет тени нейтральными — такая атмосфера сохраняется. Если на снимке есть лица,
      цвет кожи не уводится в зелень или фиолет;
    • экспозиция: осветляется тёмный кадр и кадр, в котором нет ни одного светлого пикселя
      (снято темнее, чем нужно). Намеренно тёмные кадры с бликами и светлые сцены (снег,
      белый фон) остаются как есть; учитываются лица;
    • авто-уровни: в полную силу, только если гистограмма не доходит до обоих краёв (плоский,
      блёклый кадр); пастельные и «матовые» кадры получают лишь лёгкую правку;
    • тени поднимаются, только если в них есть детали: чёрный фон и ночное небо остаются
      чёрными;
    • сильная вуаль (туман, блик через стекло, выцветший скан) убирается «дымкой» по
      тёмному каналу, яркая насыщенная графика не трогается;
    • контраст, сочность блёклых снимков, шумоподавление по оценке шума.
  «Сила» масштабирует все авто-правки. Чипы «Баланс белого / Свет / Цвет / Шум» включают
  и выключают группы. Под ними видно, что авто сделало с текущим снимком.
  Ниже ручные ползунки, они складываются с авто:
  экспозиция (светлые тона мягко скругляются, а не выбиваются), контраст, света, тени,
  белые, чёрные, температура, оттенок, сочность (бережёт кожу), насыщенность.
  Двойной щелчок по ползунку — сброс. Щелчок по числу — ввод точного значения.
  Колесо мыши меняет значение только у ползунка в фокусе: прокрутка панели безопасна.

Детали и шум — чёткость (локальный контраст), дымка, шумоподавление, цветовой шум.
Стиль        — нейтральный, яркий, тёплый, свежий, мягкий портрет, плёнка, матовый, Ч/Б,
               Ч/Б контрастный. Сила стиля регулируется.
Нейросеть    — один переключатель «Улучшать нейросетью» (Real-ESRGAN: восстанавливает детали,
               убирает JPEG-артефакты и шум). Лучшие настройки выставлены автоматически,
               «Дополнительно…» открывает силу и регулировку «Чистота ↔ Детали»: влево сильнее
               чистит шум, вправо сохраняет зерно, траву, волосы. Включается только для снимков, которые
               увеличиваются в 1,3 раза и больше (снимки больше 4 Мп и так детальные).
               Считается в фоне один раз для снимка, прогресс и оставшееся время видны в углу
               просмотра. После этого правки цвета и сила применяются мгновенно, а результат
               виден прямо в просмотре; детали лучше смотреть в 1:1.
Печать и файл
  JPEG (качество 50–100, без цветовой субдискретизации), TIFF или PNG 8/16 бит.
  Цвет: sRGB (стандарт лабораторий) или ICC-профиль принтера и бумаги (RGB или CMYK).
  Резкость для: экран / глянец / мат. Радиус рассчитывается по PPI, сила — слабо, норма, сильно.
  Яркость отпечатка: отпечаток темнее светящегося экрана. Поднимает средние тона без изменения
  чёрного и белого. Подберите по пробному отпечатку и сохраните в пресет для своей бумаги.
  Сохранять EXIF: дата и камера сохраняются, GPS удаляется, ориентация сбрасывается.


Настройки «Этот снимок»
-----------------------
Кадр: изменить рамку, повернуть, выровнять горизонт (±20°). Режим «Как в пресете /
Заполнить / Вписать» или пропорции для режимов «Оригинал» и «Сторона».
Свет, цвет и детали: показываются итоговые значения. Метка на шкале — значение пресета.
Нейросеть: как в пресете / вкл / выкл для этого снимка; там же её состояние для снимка.
«Сбросить» убирает все правки снимка. «В пресет» переносит цветовые правки в пресет для всех.
«Копировать» применяет правки к снимкам, выделенным в ленте (Ctrl или Shift + щелчок).


Советы по печати
----------------
• Фотолаборатории и минилабы (Fujifilm Frontier, Noritsu) ждут sRGB, JPEG и 300 PPI на размере отпечатка.
  240 PPI — хорошо, ниже 150 PPI детали заметно мягче.
• ICC-профиль принтера выбирайте только по требованию печатника. Не включайте управление
  цветом второй раз в драйвере принтера.
• При печати без полей держите важное в 3 мм от края: включите безопасную зону.
• Матовой бумаге нужна более сильная выходная резкость, чем глянцевой.
• Отпечаток темнее экрана: снизьте яркость монитора (80–120 кд/м²) или используйте
  «Яркость отпечатка» и сделайте пробу.
• Увеличение не создаёт настоящих деталей. Нейросеть дорисовывает правдоподобные — проверьте в 100%.


Горячие клавиши
---------------
←/→ снимки · Пробел или Z вписать/100% · \ до/после · C кадр · Ctrl+[ ] поворот
Ctrl+Z/Ctrl+Y отмена/повтор · Ctrl+S сохранить пресет · Ctrl+E подготовить · Ctrl+O папка · F1 справка
Двойной щелчок по снимку — 100% в этой точке. Ctrl+колесо — масштаб.
В узком окне кнопки над просмотром становятся значками; листать можно стрелками и лентой.


Форматы
-------
Вход:  JPEG, PNG, TIFF (8/16 бит), WebP, BMP. Встроенные профили (Display P3, Adobe RGB и др.)
       конвертируются в sRGB с мягким сжатием цветов вне охвата. Снимки до 100 Мп.
       RAW и HEIC не поддерживаются: сохраните JPEG или TIFF в редакторе.
Выход: JPEG, TIFF 8/16 бит (LZW или Deflate), PNG 8/16 бит. Встроенный ICC-профиль, PPI, EXIF без GPS.
       В той же папке пишется отчёт report.csv и report.json: статус каждого файла и что применено.


Сборка Windows-приложения
-------------------------
Нужны Windows 10/11 x64 и Python 3.12 x64 (python.org). Если py пишет
«No runtime installed that matches 3.12», выполните в PowerShell:  py install 3.12
Затем дважды щёлкните build_exe.bat. Скрипт установит зависимости, выполнит тесты, соберёт
папку PrintPrep с PrintPrep.exe, проверит self-test, создаст dist\PrintPrep-Windows-x64.zip и
установщик dist\PrintPrep-Setup.exe, а потом проверит установщик: тихая установка во временную
папку, self-test установленной программы, удаление.
Коллегам передавайте один файл PrintPrep-Setup.exe. ZIP — для тех, кому нужна переносная папка
без установки (запускать PrintPrep.exe из папки PrintPrep, рядом лежит _internal).
Пока Print Prep открыт из dist\PrintPrep, сборка не начнётся — закройте программу.
Папочная сборка запускается за 1–2 секунды даже на слабом компьютере.
Python им не нужен, права администратора тоже.
Альтернатива — workflow «Windows build» во вкладке Actions на GitHub.
Exe не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение
при первом запуске («Подробнее» → «Выполнить в любом случае»).

Запуск из исходников:
  py -3.12 -m venv .venv
  .venv\Scripts\python -m pip install -r requirements-dev.txt
  .venv\Scripts\python print_prep.py
Проверка установки: .venv\Scripts\python print_prep.py --self-test


Что сознательно не делается
---------------------------
RAW/HEIC, прямая печать на принтер (риск двойного управления цветом), ретушь кожи, облако.
Рабочее пространство — sRGB. Вывод в ICC принтера — 8 бит.
Сравнения с Photoshop по качеству и скорости не проводились: проверяйте пробными отпечатками.
