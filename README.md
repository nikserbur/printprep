# Print Prep 2.0

Локальное приложение для Windows, которое готовит папку фотографий к печати. **Открыл папку → выбрал пресет → «Подготовить».** Оригиналы не меняются, результат появляется в подпапке `PrintPrep_…`.

## Что внутри

- **Одно рабочее окно:** слева пресеты, в центре живой просмотр и лента кадров, справа инспектор. Мастера и модальных окон «Применить» больше нет.
- **Живой предпросмотр:** любой ползунок пересчитывает картинку за ~0,1–0,2 с. В масштабах 100%/200% видна настоящая резкость, шумоподавление и нейросеть. Есть шторка «до/после».
- **Пресеты и правки снимка:** клик по пресету сразу применяет его ко всей папке. Изменённый пресет помечен, его можно сохранить или вернуть. Вкладка «Этот снимок» хранит правки одного фото поверх пресета: кадр, поворот, горизонт, свет и цвет. Есть отмена (Ctrl+Z), копирование правок на выбранные снимки и перенос в пресет. Правки каждой папки сохраняются автоматически.
- **Умная авто-коррекция** настраивается по силе и составу:
  - баланс белого: обученная модель OpenCV плюс нейтральные участки;
  - экспозиция с учётом лиц; светлые сцены не затемняются;
  - тени, света, точки чёрного и белого, контраст;
  - сочность для блёклых снимков, дымка;
  - шумоподавление по оценке шума.
- **Ручной цветокор как в Lightroom:** экспозиция с мягким плечом в светах, контраст, света, тени, белые, чёрные, температура, оттенок, сочность с защитой кожи, насыщенность, чёткость, дымка, шум. Девять стилей: яркий, тёплый, плёнка, мат, Ч/Б и другие.
- **Печать:** размер в мм и PPI, пиксели, длинная сторона или оригинал. Умный кадр по лицам и главному в кадре, поля, безопасная зона, выходная резкость для экрана, глянцевой или матовой бумаги с учётом PPI. Компенсация яркости отпечатка, ICC-профиль принтера (RGB/CMYK), экранная проба и подсветка цветов вне охвата.
- **Нейросети работают локально на CPU:**
  - FSRCNN ×2 — быстро;
  - Real-ESRGAN ×4 — восстанавливает детали и чистит JPEG-артефакты;
  - YuNet — детектор лиц для кадра и экспозиции.

  При работе показывается прогресс, расчёт можно отменить.
- **Качество:** обработка во float32 от начала до конца. Читаются 16-битные TIFF/PNG, встроенные профили Display P3/Adobe RGB конвертируются точно. На выходе JPEG 4:4:4, TIFF или PNG 8/16 бит с ICC и PPI, EXIF сохраняется без GPS, 8-битный вывод сглаживается дизерингом.
- **Скорость:** экспорт идёт параллельно на нескольких ядрах и полосами, поэтому память не растёт с размером снимка. Отчёт пишется в CSV и JSON.

## Сборка и запуск

**Готовый exe для коллег:** на Windows с Python 3.12 x64 запустите `build_exe.bat`. Скрипт прогонит тесты, соберёт `PrintPrep.exe`, проверит его self-test и упакует `dist/PrintPrep-Windows-x64.zip`. Коллегам Python не нужен.

Запуск из исходников:

```bash
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python print_prep.py
```

Подробнее: [инструкция](README.txt), [план переработки](docs/PLAN.md), [исследование и решения](docs/RESEARCH.md), [проверка перед выдачей](docs/ACCEPTANCE.md), [сторонние компоненты](THIRD_PARTY.md).

Ограничения: нет RAW/HEIC и прямой печати на принтер. Рабочее пространство — sRGB, широкий охват мягко сжимается. Вывод в ICC принтера только 8-битный.
