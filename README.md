# Print Prep

Локальное desktop-приложение для пакетной подготовки фотографий к печати. Папка → размер и цвет → индивидуальная правка → готовые JPEG/TIFF в новой подпапке. Оригиналы сохраняются.

![Интерфейс Print Prep с синтетическим демонстрационным пейзажем](docs/interface.png)

- Размер в мм, PPI, автоориентация, вписывание/заполнение и поля.
- Кадрирование каждого фото, поворот, экспозиция, контраст и насыщенность.
- ICC-преобразование RGB/CMYK, встроенный профиль, приближённая ICC-проба.
- Проверка партии, guided-filter коррекция теней/светов, вибрация цвета, цветовой шум и выходная резкость.
- Встроенные пресеты, именованная библиотека и переносимые рецепты. Дополнительные панели свёрнуты.
- Опциональная локальная предобученная FSRCNN ×2 на CPU; по умолчанию выключена.
- Неизменяемые оригиналы, повторяемые рецепты, отчёт CSV/JSON, отмена.

**Windows:** установите Python 3.12 x64 для сборки и запустите `build_exe.bat`. После успешной сборки передавайте коллегам `dist/PrintPrep-Windows-x64.zip`; Python им не нужен. Альтернатива — workflow `Windows build` в GitHub Actions после отправки кода. Готовый Windows exe не входит в исходный проект: его нужно собрать и проверить на Windows.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python print_prep.py
```

Полная [инструкция](README.txt), [исследование и обоснование решений](docs/RESEARCH.md), [проверка перед выдачей коллегам](docs/ACCEPTANCE.md), [сторонние компоненты](THIRD_PARTY.md).

Ограничения: 8-битный рабочий sRGB, до 80 Мп, без RAW/HEIC, без прямой печати и распознавания лиц. Точные требования лаборатории и ICC машины нужно получить у оператора. ICC-проба предполагает sRGB-монитор и не гарантирует совпадения с отпечатком.
